# Google Play 데이터 안전성 설문지 답변 초안

## 0. 요약 답변 (Play Console 첫 화면 질문들)

- **앱이 사용자 데이터를 수집합니까?** 예 — 단, 전부 기기 내부(로컬)에만
  저장됩니다.
- **앱이 사용자 데이터를 제3자와 공유합니까?** ⚠️ [판단 필요] 아래 "위치 정보"
  항목 참고. 그 외 항목은 공유 없음.
- **데이터가 전송 중 암호화됩니까(in transit)?** 예 — 기상청/에어코리아 API
  호출은 HTTPS를 사용합니다. (실제 axios 호출 URL이 https:// 인지 코드에서
  재확인 필요)
- **사용자가 데이터 삭제를 요청할 방법을 제공합니까?** 예 — 앱을 삭제하면
  기기 내 모든 데이터가 함께 삭제됩니다(별도 서버 계정이 없어 삭제 요청 절차
  자체가 불필요). 앱 내 설정 화면에서 개별 항목도 직접 삭제 가능.

## 1. 위치 정보 (Location)

| 세부 항목 | 답변 |
|---|---|
| 대략적 위치(Approximate location) | 수집함 |
| 정확한 위치(Precise location) | 수집함 (expo-location으로 GPS 좌표 조회) |
| 수집 목적 | 앱 기능(날씨/미세먼지 조회), 개인 맞춤(해당 없음) |
| 기기 외부로 전송됨? | ⚠️ [판단 필요] 원본 좌표는 전송하지 않지만, 좌표를 변환한 기상청 격자좌표(nx,ny)·시도명은 기상청/에어코리아 공공 API로 전송됨. Google의 "공유" 정의상 "제3자 서버로 전송되는 모든 데이터"를 포함할 가능성이 있어, 보수적으로는 "예, 공유함(제3자: 대한민국 정부 공공데이터포털 API)"로 표시하는 것을 권장 |
| 선택 사항(Optional) 여부 | 선택 가능 — 위치 권한을 거부해도 앱의 다른 기능은 동작함 |
| 처리 방식 | Ephemeral(일시적) — 좌표 자체를 기기/서버 어디에도 저장하지 않고 조회 즉시 변환·폐기 |

## 2. 개인 정보 (Personal info)

이름, 이메일, 전화번호, 주소, 사용자 ID 등 — **수집하지 않음** (회원가입/로그인
기능 없음).

## 3. 캘린더 (Calendar)

- react-native-calendar-events로 오늘 일정의 제목·시각을 읽음.
- **기기 외부로 전송되지 않음** — 앱 실행 중 메모리에서만 참조, 저장하지 않음.
- Play Console 데이터 유형 분류상 "앱 활동" 또는 "기타" 중 어디에 해당하는지는
  Play Console 최신 UI에서 "캘린더 이벤트" 항목이 별도로 있는지 확인 필요
  ⚠️ [판단 필요].

## 4. 앱 활동 / 앱 정보 및 성능 (App activity / App info and performance)

- 크래시 로그, 진단 데이터, 분석 데이터: **수집하지 않음** (Sentry 등 크래시
  리포팅 미도입 상태 — 도입 시 이 문서와 개인정보처리방침의 "5. 개인정보처리
  위탁" 항목을 함께 갱신해야 함).

## 5. 기기 또는 기타 ID (Device or other identifiers)

- 홈 Wi-Fi BSSID(MAC 주소 성격의 식별자)를 기기 내부(AsyncStorage)에만 저장.
- **기기 외부로 전송되지 않음.**
- Play Console에 "기기 ID" 관련 문항이 있다면 "수집함(기기 내부 저장, 공유
  안 함)"으로 답변.

## 6. 데이터 보안 관행 체크리스트

- [x] 사용자가 데이터 삭제를 요청할 수 있음 (앱 삭제 / 앱 내 설정)
- [x] 전송 중 데이터 암호화(HTTPS)
- [ ] 독립적인 보안 검토를 받았는지 — [사용자 확인 필요, 통상 소규모 앱은 해당 없음]
- [x] Google Play의 Families 정책 대상 아님 (아동 대상 앱 아님 — 필요 시 확인)

## 최종 제출 전 체크리스트

1. Play Console 실제 문항과 이 문서의 매핑이 최신인지 대조 (문항 구성이 자주 바뀜)
2. ⚠️ 표시된 "위치 정보 공유" 판단을 확정 (보수적으로 "공유함"을 권장하는 이유:
   Google 정책은 익명화·변환 여부와 무관하게 "기기 밖으로 나가는 데이터"를
   폭넓게 "공유"로 취급하는 경향이 있음 — 다만 최종 판단은 Play 정책팀 가이드
   또는 법률 자문에 따를 것)
3. Sentry 등 크래시 리포팅을 도입하면 이 문서의 "4. 앱 활동" 항목을 반드시 갱신
