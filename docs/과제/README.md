## 이 과제의 특수 조건

아맞다는 **이미 구현된 앱이 존재하는 상태**에서 이 프로세스를 적용한다.
그래서 두 가지를 의식적으로 지킨다.

1. **공감~구상(1~3단계)에서는 앱을 언급하지 않는다.**
   해결책을 아는 채로 쓰면 조사가 결론의 정당화가 된다. 앱은 4단계 구현에서 처음 등장한다.
2. **대신 5단계 확인에서 유리하다.**
   앱이 이미 '놓친 항목'을 기록하는 구조라, 1단계에서 세운 가설을 실제 사용 데이터로
   되받을 수 있다. 1단계에서 **무엇을 측정할지**를 미리 정해두면 7단계가 한 줄로 꿰인다.
