## A. 학술 연구 — 사람은 무엇을 어떻게 잊는가

> 2026-09-30 신설. 통계(B)가 **"얼마나"**를 말한다면 이 장은 **"왜"**의 근거다.
> 교재의 '문화/기술 동향 탐색'보다는 '유사 사례 조사'의 이론적 배경에 해당한다.
> 전부 동료심사 학술지 게재 논문이며, 해외 표본이라는 한계가 공통으로 붙는다.

### A-1. 일상 기억 실패의 64%는 '할 일을 잊는 것'이다 — ★★★

| 항목 | 수치 |
|---|---|
| 기록된 일상 기억 실패 | 1,319건 (7일 일기법, 152명) |
| **미래기억(PM) 실패** — 해야 할 일을 제때 떠올리지 못함 | **838건, 64%** |
| 회상기억(RM) 실패 — 알던 것을 떠올리지 못함 | 267건, 20% |
| 주의 실수(absent-minded) | 214건, 16% |
| 심각도 평정 (높을수록 심각) | PM 2.40 > RM 2.06 > 주의 실수 1.98 |
| 결과(손해)가 따른 실패 | 전체의 48% |
| 연령 | **청년층(19~30세)이 고령층보다 PM 실패를 훨씬 많이 보고** |

- **출처**: Niedźwieńska, A., Sołga, J., Zagaja, P., & Żołnierz, M. (2020). Everyday memory failures across adulthood: Implications for the age prospective memory paradox. *PLOS ONE*, 15(9), e0239581. [원문](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0239581)
- **확인일**: 2026-09-30 (원문 확인함)
- **용도**: "챙기는 것을 잊는다"는 현상이 학술적으로 **미래기억(prospective memory) 실패**라는
  이름을 가진, 일상 기억 실패 중 **가장 흔하고 가장 심각하게 느껴지는 유형**이라는 근거.
  `00` 1장의 "꼼꼼한 사람은 안 까먹는다"를 반박하는 재료이기도 하다.
  또 **젊은 층일수록 더 많이 보고한다**는 점은 사용자군 A(20·30대)와 맞물린다
- **한계**: 폴란드 표본, 7일 자기보고. 청년층이 많이 보고하는 이유는 실제 실패가 많아서가 아니라
  **일정이 더 빡빡해서**일 수 있다(논문 자체가 이 역설을 다룬다). "우산·소지품"만 따로 본 연구가 아니다

### A-2. 미래기억 실패는 더 드물지만 기분을 더 크게 망친다 — ★★★

| 항목 | 수치 |
|---|---|
| 기억 실패가 보고된 평가 시점 | 전체의 **33.2%** (7일간 매일 저녁, 166명, 20~79세) |
| 회상기억 실패 / 미래기억 실패 | 18% / 15% |
| 가장 흔한 미래기억 실패 | **약 먹는 것을 잊음** (평가 시점의 6%) |
| 정서에 미친 영향 | 미래기억 실패가 있던 날 긍정정서↓(b=−0.801) · 부정정서↑(b=1.241), **회상기억 실패보다 영향이 큼** |

- **출처**: Mogle, J., Muñoz, E., Hill, N. L., Smyth, J. M., & Sliwinski, M. J. (2019). Daily memory lapses in adults: Characterization and influence on affect. *The Journals of Gerontology: Series B*, 74(1), 59–68. [원문](https://academic.oup.com/psychsocgerontology/article/74/1/59/3003314)
- **확인일**: 2026-09-30 (초록·본문 요약 확인)
- **용도**: ①**3일에 한 번꼴**로 무언가를 잊는다는 빈도의 참고치 ②놓침의 비용이 돈·시간만이
  아니라 **그날의 기분**이라는 점(3.3의 4번 질문 "짜증의 대상은 물건인가 자신인가"와 연결)
  ③가장 흔한 미래기억 실패가 **복약**이라는 점은 보호자 사용자군 B와 연결된다
- **한계**: 미국 표본. "잊은 날 기분이 나빴다"는 상관이지 인과가 아니다

### A-3. 사람은 원래 기억을 바깥에 맡긴다 (인지 오프로딩) — ★★

- **개념**: 내부 처리 부담을 줄이기 위해 **몸의 행동이나 외부 도구를 쓰는 것**을 인지 오프로딩
  (cognitive offloading)이라 한다. 약속을 기억할 때 머리로 외울지, 달력에 적거나 휴대폰
  알림으로 **"내려놓을지"** 고르는 것이 대표 예다
- **비용**: 외부에 맡긴 정보는 머리에 덜 남는다 — 도구 없이 기억하는 능력은 줄어든다
- **출처**: Risko, E. F., & Gilbert, S. J. (2016). Cognitive Offloading. *Trends in Cognitive Sciences*, 20(9), 676–688. doi:10.1016/j.tics.2016.07.002 (서지는 Crossref로 확인, 피인용 1,250회+) /
  내용은 [ScienceDaily 2016-08-16 보도](https://www.sciencedaily.com/releases/2016/08/160816134021.htm)로 확인
- **확인일**: 2026-09-30
- **용도**: 3.2의 **동거인·현관 배치·메모** 전부가 같은 행동(기억을 바깥에 맡기기)의 다른
  형태라는 이론적 틀. 특히 **동거인은 '사람에게 맡긴 오프로딩'**이고, `B-2`·`B-3`은
  그 맡길 곳이 줄어드는 중이라는 뜻으로 읽힌다
- **한계**: 🟡 **본문 미열람**(유료). 초록은 출판사가 비공개 처리, 내용은 대학 보도자료 기준이다.
  인용은 개념 정의 수준으로만 할 것

### D-2. 앱이 아닌 해결책 — ★ (관찰 기반, 필드에서 검증)
