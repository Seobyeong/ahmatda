# 공감 단계 설문 — 구글폼 붙여넣기용

> 원본·분석 교차표: [`01-공감-조사도구.md`](01-공감-조사도구.md) D장. 이 문서는 **폼에 그대로 옮기는 용도**다.
> 원본에서 바꾼 것: ① 문항 수 표기(11문항) ② 연락처 수집 동의 문구 ③ 5번 "0회" 응답자는 6~8·10번 건너뛰기
> ④ 12번(선택) 추가 — [`01-공감-인터뷰질문-기록방식전환.md`](01-공감-인터뷰질문-기록방식전환.md) 가설의 분포 확인용. 빼도 분석에 지장 없다.
> 규칙: 문항에 '앱'이라는 단어를 쓰지 않는다.

## 폼 설정 (만들기 전에)

- 설정 → 응답 → **이메일 주소 수집: 수집 안함**
- **응답 횟수 1회로 제한: 끄기** (켜면 구글 로그인이 필요해 응답률이 떨어진다)
- 모든 문항 **필수**, 단 9번·12번·연락처는 선택
- 섹션 4개로 나눈다 (5번 답에 따라 이동)

## 섹션 1 — 기본 정보

**폼 제목**
```
아침에 집을 나설 때 — 짧은 설문
```

**폼 설명**
```
아침에 집을 나설 때의 경험을 묻는 설문입니다. 학교 과제로 진행하며 3분 정도 걸립니다.
이름·이메일 등 개인을 식별하는 정보는 수집하지 않습니다.
(마지막의 인터뷰 연락처 칸은 원하시는 분만 적어주시면 됩니다.)
```

**1. 연령대** — 객관식
```
10대
20대
30대
40대
50대 이상
```

**2. 현재 거주 형태** — 객관식
```
혼자 산다
가족과 산다
룸메이트·친구와 산다
기타
```

**3. 평일 주 이동수단** — 객관식
```
지하철·버스
자차
도보·자전거
기타
```

**4. 평일 집을 나서는 시각이 일정한 편인가요?** — 객관식
```
거의 일정하다
그때그때 다르다
```

**5. 최근 한 달간, 필요한 물건을 안 챙기고 나온 적이 몇 번쯤 있었나요?** — 객관식, **답변을 기준으로 섹션 이동** 켜기
```
0회            → 섹션 3으로 이동
1~2회          → 다음 섹션(섹션 2)
3~5회          → 다음 섹션(섹션 2)
6회 이상       → 다음 섹션(섹션 2)
```

## 섹션 2 — 놓쳤던 경험

**6. 그때 놓친 것을 모두 골라주세요** — 체크박스 (기타 허용)
```
우산
지갑·카드
충전기·보조배터리
이어폰
마스크
서류·노트북
약
운동복·장비
신분증·사원증
열쇠
```

**7. 보통 언제 알아차리셨나요?** — 객관식
```
집 앞·엘리베이터에서
이동 중에
목적지 도착 후
그게 필요해진 순간에
끝내 모르고 지나감
```

**8. 알아차렸을 때 보통 어떻게 하셨나요?** — 객관식 (기타 허용)
```
집으로 돌아갔다
그냥 갔다
새로 샀다
빌렸다
일정을 바꿨다
```

**10. 마지막으로 뭔가를 놓쳤던 날, 그 하루에 미친 영향은 어느 정도였나요?** — 선형 배율 1~5
```
1: 전혀 없었음
5: 꽤 지장이 있었음
```

> 폼 안에서는 10번이 9번보다 먼저 나온다. 번호는 분석용이므로 **폼에는 번호를 붙이지 않는다.**

## 섹션 3 — 평소 방법

**9. 안 까먹으려고 쓰는 방법이 있다면 자유롭게 적어주세요** — 단답형, 선택
```
(예: 전날 밤 현관에 둔다, 휴대폰 메모, 가족이 말해준다 …)
```

**11. 지금 쓰고 계신 것을 모두 골라주세요** — 체크박스
```
스마트워치·밴드
AI 스피커
스마트 도어락
스마트 조명·플러그
로봇청소기
해당 없음
```

**12. (선택) 일정이나 할 일은 주로 어디에 적어두시나요?** — 체크박스 (기타 허용), 선택
```
휴대폰 캘린더
휴대폰 할 일·메모 기능
종이 다이어리·메모지
달력·화이트보드
따로 적지 않고 기억한다
```

## 섹션 4 — 인터뷰 참여 (선택)

**섹션 설명**
```
아침 준비에 대해 40분 정도 이야기를 나눠주실 분을 찾고 있습니다. (작은 사례를 드립니다)
연락처는 인터뷰 일정 조율에만 사용하고, 과제가 끝나면 바로 삭제합니다.
원하지 않으시면 비워두고 제출해 주세요.
```

**연락처 (전화번호 또는 카카오톡 ID)** — 단답형, 선택
