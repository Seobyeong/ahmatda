## 1. 아홉 집단을 넷으로 — 영향도 × 접근성

`01-공감.md` 4.1의 9개 집단에 적용할 필터.

| | 접근하기 쉬움 | 접근하기 어려움 |
|---|---|---|
| **영향 큼** | 매일 정해진 시각에 나가는 사람 / 동거인 / 보호자 → **인터뷰** | 현장직·교대근무자 → 가능하면 1명, 아니면 설문으로 |
| **영향 작음** | 편의점·역사 매장 → **관찰로 대체** (4.4의 3번) | 역무원·유실물센터, 직장·학교, 교통기관 → **이번 범위에서 제외** |

- 남기는 넷: **당사자 · 동거인 · 보호자 · 현장직**
- 역무원 인터뷰는 정식 섭외가 필요해 학부 과제로는 사실상 불가 → 관찰로 대체
- **제외한 이유를 문서에 남기는 것 자체가 평가 대상**이다

## 2. 인터뷰 대상자는 설문에서 뽑는다 (깔때기)

**설문 30명 → 인터뷰 동의자 → 응답으로 선별 → 5~8명**

| 기준 | 판단 문항 | 이유 |
|---|---|---|
| 반드시 포함 | Q5가 3~5회 이상 | 최근 사건을 구체적으로 기억함 → 인터뷰 파트2가 살아난다 |
| 반드시 포함 | Q2 "혼자 산다" ↔ "가족과 산다" 각각 | 핵심 대조축 (4.3의 #1 vs #4) |
| 최소 1명 | Q2 자녀 있는 응답 | 보호자(사용자군 B) |
| 최소 1명 | Q4 "그때그때 다르다" | 현장직·교대(사용자군 C) 탐색 |
| 최소 2명 | (신규 문항) 써보고 그만둔 사람 | 이탈자 — 문제 인식 + 기존 해법 실패를 경험한 집단 |
| ⚠️ 제외 금지 | Q5가 0회 | **"안 놓치는 사람은 무엇을 다르게 하나"**가 가장 값진 대조군 |

## 3. 표본이 터지지 않게

4.3에 이미 대조축이 셋(동거 형태 × 출발 시각 × 이동 수단) 있다.
여기에 **도구 이력까지 쿼터로 넣으면 7명으로 조합을 못 채운다.**
→ **도구 이력은 쿼터가 아니라 전원 기록 항목**으로 두고, "이탈자 최소 2명"만 보장한다.

## 4. 모집 경로와 표본 편향

| 집단 | 경로 |
|---|---|
| 1인가구 직장인·대학생 | 학교 커뮤니티, 자취 오픈채팅, 동아리 |
| 동거가구 | 지인 (단, 지인만으로 채우지 말 것) |
| 보호자 | 지인의 부모 세대, 학부모 커뮤니티 |
| 현장직·교대 | 스노우볼(지인의 지인)이 현실적 |

> 🔴 **지인 표본 편향이 이 조사의 최대 위험.** 지인은 생활 패턴이 비슷해 같은 답을 한다.
> `00` 1장의 고정관념("내가 겪었으니 남들도 똑같이")이 표본 단계에서 그대로 재현된다.
> **1인가구 응답자 중 최소 2명은 모르는 사람으로 채운다.**

## 5. 제외 기준 (누구를 안 부르는지도 적는다)

- 재택근무로 평일에 거의 안 나가는 사람 → 범위가 '매일 반복되는 이동'(`00` 4.2)
- 여행·행사 준비 경험만 말하는 사람 → 비반복 상황은 제외 범위
- "그런 적 없다"만 하고 사건을 못 떠올리는 사람 → 인터뷰 대신 설문으로
