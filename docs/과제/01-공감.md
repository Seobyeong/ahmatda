## 0. 전제 — '리셋'

교재는 공감에 도달하려면 "원래 이런 거야", "지금은 이렇게 하고 있어"라는 사고를
멈추는 마음가짐 '리셋'이 필요하다고 말한다. 이 프로젝트는 **이미 만들어진 앱이 있어서
리셋이 특히 어렵다.**

> **1~3단계 문서에서는 우리가 만든 해결책을 언급하지 않는다.** 앱은 4단계 구현에서 처음 등장한다.
> 단, 이미 시장에 있는 것들을 조사하는 것은 교재가 요구하는 데스크 리서치이므로 해당되지 않는다.

버려야 할 고정관념의 구체적 목록은 [`00-주제-목표-범위.md` 1장](00-주제-목표-범위.md) 참조.

## 1. 사전 단계 → [별도 문서](00-주제-목표-범위.md)

교재가 공감 단계의 첫 과업으로 제시한 "프로젝트의 주제, 목표, 범위 설정"과
3장의 사전 단계(고정관념 제거 · 주제 설정 · 자문 체크리스트)는
분량이 커서 [`00-주제-목표-범위.md`](00-주제-목표-범위.md)로 분리했다.

요약하면:

- **관심 영역** — 매일 반복되는 '집을 나서는 순간'
- **문제 유형(가설)** — 기억과 주의에 의존하는 일상 준비가, 조건이 매일 바뀌는 상황에서 구조적으로 실패한다
- **사용자군** — 후보 A(1인가구) / B(보호자) / C(현장직)를 병렬로 두고 **2단계 발견에서 선별**
- **가장 약한 고리** — "반드시 해결해야 할 문제인가, 그냥 불편함인가". 반복성·비용의 이전·
  심각도의 편차 중 최소 둘이 조사로 받쳐줘야 한다

> 교재는 공감 단계의 과업을 "사전단계에서 1차적으로 설정한 주제·목표·범위를 **확정**한다"로
> 규정한다. 따라서 자료 수집이 끝나면 00 문서로 돌아가 확정하고, 바뀐 내용은 그 문서의
> **변경 이력** 표에 기록한다.

## 2. 내부 요인 — 개인적 동기와 자원

> 교재: 프로젝트를 선택한 개인적 동기·배경, 자신의 경험에서 출발한 문제의식을 성찰하고
> 역량·가용 자원·제한 요소를 점검한다.

**[직접 작성 필요]** — 아래 항목만 채우면 된다. 이 부분은 대신 쓸 수 없다.

| 항목 | 내용 |
|---|---|
| 이름 / 학번 |  |
| 가장 최근에 깜빡했던 날 — **한두 줄이면 충분하다** (언제, 무엇을, 그래서 어떻게 됐는지) |  |
| 그때 느낀 감정 (짜증? 자책? 체념? 아니면 아무렇지 않았나?) |  |
| 그 뒤로 내가 실제로 바꾼 행동 (효과가 있었는지 포함) |  |
| 내가 가진 역량 |  |
| 가용 자원 (시간, 접근 가능한 인터뷰 대상, 장비) |  |
| 제한 요소 (기간, 예산, 조사 가능한 표본의 한계) |  |

> **극적인 사건일 필요가 없다.** 오히려 사소하고 반복적인 날이 이 주제에 맞는 재료다.
> 이유는 [`00-주제-목표-범위.md` 2.0 배경](00-주제-목표-범위.md)에 정리해 뒀다 —
> 교재가 Recognition 축을 **가설추론(Abduction)**과 연결하는 이상, 개인 경험은
> **가설의 출발점**이지 가설 자체가 아니기 때문이다.
>
> **역할 분담**
> - **배경(00 문서 2.0)** = 사회적 질문. 거시 데이터(`B-1`, `B-2`, `C-1`)가 담당한다
> - **내부 요인(여기)** = 개인적 동기. 경험을 그대로 쓰되 **근거로는 쓰지 않는다**
>
> ⚠️ **"내가 겪은 문제니까 남들도 똑같이 겪는다"**가 이 프로젝트에서 가장 위험한
> 고정관념이다([`00` 1장](00-주제-목표-범위.md)). 경험은 질문을 만들고, 데이터가 그
> 질문을 받는다. 순서를 바꾸면 표본 1명짜리 일반화가 된다.
>
> 여기 적은 내용은 뒤의 **자기관찰 로그**(4.4)의 0번 항목으로도 이어진다.

## 3. 데스크 리서치 (요약)

> 자료의 출처·확인일·신뢰도·한계는 전부
> [`01-공감-데스크리서치-자료.md`](01-공감-데스크리서치-자료.md)에 있다.
> 여기서는 **그래서 무엇을 알게 되었는가**만 쓴다. 아래 `B-1` 같은 코드는 그 문서의 항목 번호다.

### 3.1 거시 환경

| 축 | 알게 된 것 | 이 문제와의 연결 | 근거 |
|---|---|---|---|
| **사회** | 1인가구가 전체 가구의 **36.1%**(2024년, 804만 5천 가구)로 역대 최대. 20·30대만 합쳐도 35.2% | **"너 우산 챙겼어?"라고 말해주던 사람**이라는 비공식 안전망이 구조적으로 사라지는 중. 3.2에서 보듯 이것이 현재 가장 강력한 기존 해결책이다 | `B-2` ★★★ |
| **시장** | 비 오는 날 편의점 우산 매출이 전년 동기 대비 **630% 급증**, 유통사가 우산 공급을 **주 2회 → 주 7일로 전환** | 급구매는 **준비 실패를 돈으로 덮은 흔적**이다. 공급 체계를 바꿨다는 것은 그 수요가 **상시화**되었다는 뜻 | `C-1` ★★ |
| **환경** | 국지성 호우가 잦아지고 강도가 세지는 추세. 2050년 남부 대부분 아열대화 전망 | **전날 밤의 예측이 점점 덜 맞게 되는 환경.** 준비를 미리 해두는 전략의 유효기간이 짧아진다 | `C-2` ★ *1차 자료 미확인* |
| **기술** | 알림 피로도에 대한 정성적 진술만 확인, **인용 가능한 수치 없음** | 기존 리마인더가 왜 안 통하는지의 유력한 후보지만 **데스크 자료로 주장하지 않는다** | `C-3` 🔴 |
| **정책** | 이 단계에서 직접 영향을 주는 규제 없음 | 개인정보(위치·일정 접근) 이슈는 구현 단계 사항 | — |

### 3.2 미시 환경 — 사람들이 **지금 이미 쓰고 있는 방법**

경쟁 구도를 '앱 대 앱'으로 보면 안 된다. 이 문제의 실제 경쟁자는 대부분 **앱이 아니다.**

| 현재 해결책 | 강점 | 실패하는 지점 |
|---|---|---|
| **동거인(가족·배우자·룸메이트)** — 가장 강력한 기존 해결책 | 무료, 맥락을 알고, 적절한 순간에 말해줌 | 1인가구에는 아예 없음(36.1%, `B-2`). 상대가 바쁘면 작동 안 함 |
| 현관 앞 물리적 배치 (문고리에 우산 걸기, 신발장 위에 놓기) | 시야에 강제로 들어옴 | 전날 밤의 예측이 맞아야만 작동 (`C-2`에 따라 점점 불리) |
| 날씨 앱 / 옷차림 추천 앱 (핏프티·웨더핏·옷차림표·날씨돌) | 정보는 정확, 옷차림까지 번역해줌 | **들고 나갈 것**은 다루지 않음. 앱을 **열어야** 함. 같은 기온에 **모두 같은 답** (`D-1`) |
| 할일/메모 앱, 미리알림 | 기록은 확실. 잠금화면·위젯으로 **열지 않아도 보이게** 하는 앱도 있음 | **적어둔 것만** 알려줌. 떠올리지 못한 것은 다루지 못함 (`D-3`) |
| 알람·캘린더 알림, 장소 알림 | 확실히 울림. 기본 리마인더에는 **"장소를 떠날 때" 알림도 무료로 있음** | 시각 알림은 나가는 순간과 어긋남. 장소 알림은 **있지만 잘 쓰이지 않는 것으로 보임** — 이유는 필드에서 확인 (`D-3`) |
| 편의점 급구매 | 즉시 해결 | 사후 보정. 비용을 지불해 문제를 덮음 (`C-1`이 그 규모를 보여줌) |
| 체념 ("그냥 맞고 감") | — | 이 선택지를 고르는 비율이 높다면 **문제 자체를 재정의해야 한다** |

> 이 표에서 가장 중요한 행은 **맨 윗줄**이다. `B-2`와 맞물려 **"사람이 하던 일이 사라지는 중"**
> 이라는 구조적 서사를 만든다. 인터뷰 파트4에서 반드시 검증할 것.

### 3.3 데스크 리서치로 알 수 없는 것 → 필드로 넘기는 질문

1. 사람들은 **언제** 알아차리는가? (현관 앞 / 엘리베이터 / 지하철 / 필요한 순간)
2. 알아차린 뒤 **실제로 무엇을 하는가**? 되돌아가는가, 포기하는가, 사는가?
3. 기존 방법(메모·알람·동거인)이 **어떤 상황에서 깨지는가**?
4. 놓쳤을 때 짜증의 대상은 **물건인가, 자기 자신인가**? (효능감·자책의 문제인가)
5. 1인가구와 동거가구의 경험은 실제로 다른가? (`B-2`는 배경일 뿐 인과가 아니다)
6. 누군가를 **챙겨주는 입장**의 사람은 어떤 부담을 지고 있는가?
7. **1회 놓침의 실제 비용은 얼마인가?** (원 단위, 분 단위 — 가치 주장의 유일한 근거)

> 7번을 포함해 자료집 **F장의 1~3번은 데스크 리서치로는 절대 구할 수 없다.**
> 그래서 필드 리서치를 하는 것이고, 직접 만든 근거라 과제에서 가장 높은 평가를 받는 부분이다.

## 4. 필드 리서치 설계

> 교재: 이해관계자 관계지도 · 사용자 여정맵 · 행동 매핑 · 공감지도 · 인터뷰 · 관찰법

### 4.1 이해관계자 도출 — 마켓 4.0 관점 확장

교재는 `제품 → 고객·소비자 → 사용자·인간 → 이해관계자·사회`로 관점을 확장해야
문제의 원인과 맥락, 구조까지 통찰할 수 있다고 말한다. 사용자 한 명만 보면 문제의 일부만 보인다.

| 구분 | 이해관계자 | 이 문제와의 관계 | 조사 우선순위 |
|---|---|---|---|
| 직접 | 매일 정해진 시각에 나가는 사람 (직장인·대학생) | 놓침을 직접 겪는 당사자 | **1순위 (인터뷰)** |
| 직접 | 동거인 (배우자·부모·룸메이트) | 현재 가장 강력한 해결책이자, **챙겨주는 부담**을 지는 쪽 | **1순위 (인터뷰)** |
| 직접 | 보호자 (아이 준비물, 고령 부모 복약) | 본인 것 + 타인 것을 이중으로 챙김. 심각도가 급등하는 지점 | **2순위 (인터뷰 1명)** |
| 직접 | 교대근무자·현장직·외근직 | 출발 시각이 불규칙하고, 놓치면 곧 업무 손실(안전장비·장비) | 2순위 |
| 간접 | 역무원 / 유실물센터 직원 | 연 16.7만 건을 처리하는 비용의 실제 부담자 (`B-1`) | 3순위 (가능하면 1명) |
| 간접 | 역사 내 편의점·매장 | 급구매 수요의 수혜자 = 문제의 **경제적 흔적** (`C-1`) | 3순위 (관찰로 대체 가능) |
| 간접 | 직장·학교 | 준비물 누락으로 생기는 지연·재작업의 부담자 | 4순위 |
| 간접 | 대중교통 운영기관 | 유실물 접수·보관·반환 시스템 운영 | 4순위 |
| 제공자 | 날씨앱·옷차림앱·할일앱 | 기존 해결책 제공자 = 대체재 (`D-1`) | 데스크로 대체 (완료) |

### 4.2 이해관계자 관계지도 (수집 후 작성)

중심에 '외출 준비'를 두고 위 표의 이해관계자를 배치한 뒤,
**정보가 흐르는 방향**과 **부담이 이동하는 방향**을 화살표로 표시한다.
특히 다음 두 흐름을 명시할 것:

- `동거인 → 당사자` (상기 정보의 흐름) — 1인가구에서는 이 선이 끊긴다
- `당사자 → 유실물센터 / 편의점` (비용의 이전)

### 4.3 인터뷰 표본 설계 — 5~8명

표본이 작으므로 **수가 아니라 대조축**으로 설계한다.

| # | 동거 형태 | 출발 시각 | 이동 수단 | 비고 |
|---|---|---|---|---|
| 1 | 1인가구 | 고정 (통근) | 대중교통 | 기준 사례 (사용자군 A) |
| 2 | 1인가구 | 고정 (통학) | 대중교통 | 연령 대조 |
| 3 | 1인가구 | 불규칙 | 대중교통 | 교대·프리랜서 (사용자군 C 탐색) |
| 4 | 동거 (가족) | 고정 | 대중교통 | **1인가구와 핵심 대조** |
| 5 | 동거 (룸메이트) | 고정 | 대중교통 | 챙겨주는 관계가 약한 동거 |
| 6 | 동거 (자녀 있음) | 고정 | 자차 | **보호자 역할(B) + 짐 제약 없음** |

### 4.4 관찰법 · 행동 매핑

교재의 행동 매핑은 **물리적 공간에서의 행동**을 시각화하는 기법이다. 이 주제에 그대로 맞는다.

1. **현관 사진 수집** (인터뷰 대상자에게 동의받고 촬영 요청)
   - 무엇이 **어디에** 놓여 있는가: 문고리, 신발장 위, 현관 선반, 벽 후크
   - 이건 사람들이 이미 스스로 만들어둔 **아날로그 시스템**이다. 말로는 "특별히 안 해요"라고
     하면서 사진에는 시스템이 찍혀 있는 경우가 많다 → **말과 행동의 불일치가 최고의 인사이트**
2. **자기관찰 로그 (본인, 2주)**
   - 매일 나가기 직전 현관 사진 1장
   - 귀가 후 한 줄: "오늘 없어서 아쉬웠던 것 / 괜히 들고 나간 것"
   - 시작일: ______ ~ 종료일: ______
3. (선택) 비 오는 날 지하철역 편의점 우산 매대 15분 관찰 — `C-1`의 급구매 행동을 실물로 확인
