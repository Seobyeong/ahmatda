# 공감 단계 추가 인터뷰 질문 — 일정·할 일 기록 방식과 바꿔본 경험

> 본 인터뷰 가이드는 [`01-공감-조사도구.md`](01-공감-조사도구.md) B장이다. 이 문서는 그 가이드에
> **끼워 넣는 추가 질문 묶음**이며, A장의 절대 규칙 3가지를 그대로 따른다.
> 배경 가설과 논의 기록: [`_메모-전환장벽-가설.md`](_메모-전환장벽-가설.md) 1·2장

## 0. 이 질문으로 알고 싶은 것

> 사람들이 일정·할 일을 기록하는 방식을 **바꾸려다 그만둔다면, 무엇 때문에 그만두는가.**

출발 가설은 "새 방식에 다시 맞추는 과정이 귀찮아서"다. 이 귀찮음이 어느 층에서 오는지 가른다.

| 층 | 예시 |
|---|---|
| **데이터** | 쌓아둔 일정·목록·반복 설정을 다시 옮기거나 입력하는 일 |
| **습관·관계** | 손에 익은 순서, 어디에 뭐가 있는지 아는 감각, 다른 사람과 같이 보는 일정 |

가설이 틀릴 수도 있다. "바꿀 이유가 없었다", "애초에 안 적는다"는 답도 똑같이 중요한 결과다.

## 1. 끼워 넣는 위치와 시간

- **위치:** B-4 파트 3의 "휴대폰 알림이나 메모 앱 써보신 적 있어요?" **바로 뒤**
- **시간:** 5~7분. 전체가 50분을 넘기지 않도록 **파트 3의 "손과 눈" 질문은 ★ 하나만** 묻는다
- 시간이 빠듯하면 2장의 **★ 표시 질문만** 묻는다

## 2. 질문 리스트

### 2-1. 지금 어떻게 기록하는가 (모두에게)

1. ★ 요즘 일정이나 할 일은 **어디에** 적어두세요? (휴대폰·종이·달력·안 적음 등)
2. 그걸 쓰신 지 얼마나 됐어요? 그 **전에는** 뭐로 하셨어요?
3. 하루에 그걸 **언제** 열어보세요? 마지막으로 연 게 언제예요?

> 1번에서 **"안 적어요, 그냥 기억해요"**라고 하면 2-2로 가지 말고 **2-3**으로 간다.

### 2-2. 바꿔본 경험 (기록하는 사람에게)

4. ★ 다른 방식으로 바꿔보려고 했던 **가장 최근 때** 얘기해 주세요. 왜 바꿔보려고 하셨어요?
5. ★ 그때 **어디까지** 하다가 그만두셨어요?
   - 프로빙: 깔아만 봤는지 / 옮기다가 멈췄는지 / 며칠 쓰다가 돌아왔는지
6. 원래 쓰던 데 있던 일정이나 목록은 **그때 어떻게 하셨어요**? (옮김 / 일부만 / 그냥 둠)
7. 그 일정을 **같이 보는 사람**이 있어요? (가족·애인·회사)
8. 다시 원래 걸로 돌아왔을 때, **그 순간** 어떤 생각이 드셨어요?

> 바꿔본 적이 없다고 하면: "그럼 바꾸고 싶다고 생각했던 순간은 있었어요? 그때 왜 안 하셨어요?"
> 그것도 없으면 억지로 끌어내지 말고 넘어간다 — **"바꿀 이유가 없다"**도 결과다.

### 2-3. 기록하지 않는 사람에게

9. ★ 적지 않고 기억하시는 거면, **마지막으로 잊어버렸던 약속이나 할 일**은 뭐였어요?
10. 예전에 적어보려고 했던 적 있어요? 그때 **왜 그만두셨어요**?
11. 그럼 다른 사람이 대신 기억해 주는 경우가 있어요? (파트 4 사람 요인으로 이어짐)

### 2-4. 관찰 (동의할 때만)

12. 지금 쓰시는 일정 화면을 **잠깐 보여주실 수 있어요**? 내용은 안 적고, 어떻게 적으시는지만 볼게요.
    - 볼 것: 제목 길이("치과" / "3시 치과 — 보험증 챙기기"), 반복 일정 유무, 색·분류 사용, 다른 사람과 공유 표시
    - **사진은 찍지 않는다.** 본 것은 기록 템플릿에 말로만 적는다

## 3. 하지 말 것

| 이렇게 묻지 말고 | 이유 |
|---|---|
| "왜 안 바꾸세요?" | 의견을 묻는 질문이라 그럴듯한 이유가 재구성된다 (규칙 2) |
| "옮기기 쉬우면 바꾸실 거예요?" | 미래 행동을 묻는 질문이라 거의 다 "네"라고 한다 (규칙 1) |
| "다른 앱이 자동으로 옮겨주면…" | 해결책 제시 — 1단계에서 금지 (규칙 1) |
| 특정 앱 이름을 먼저 꺼내기 | 상대가 쓰는 앱 이름은 **상대가 먼저 말할 때만** 받아 적는다 |

## 4. 기록 템플릿 추가 칸

C장 기록 템플릿 맨 아래에 붙인다.

```
■ 일정·할 일 기록 방식
   지금: ____________ (사용 기간 ____ / 이전: ____________)
   안 적음 ☐  →  마지막으로 잊은 것: ______________________

■ 바꿔본 경험   없음 ☐ / 있음 ☐
   바꾸려던 이유: ______________________
   그만둔 지점:   설치만 ☐ / 옮기다가 ☐ / 며칠 쓰다가 ☐ / 기타 ______
   기존 기록 처리: 옮김 ☐ / 일부만 ☐ / 그냥 둠 ☐
   같이 보는 사람: ______________________
   원문 인용: "                                              "

■ 일정 화면 관찰 (본 경우만, 내용 말고 형식)
   제목 길이: 짧음 ☐ / 설명 있음 ☐   반복 일정 ☐   색·분류 ☐   공유 ☐

■ 장벽 판정 (인터뷰 끝나고 내가 판단)
   데이터 ☐ / 습관·관계 ☐ / 동기 없음 ☐ / 기록 안 함 ☐ / 판단 불가 ☐
```

## 5. 답을 읽는 기준

인터뷰가 모두 끝난 뒤, 4장의 "장벽 판정"을 모아서 본다.

| 이런 답이 많으면 | 해석 | 다음 단계로 넘길 질문 |
|---|---|---|
| "다시 다 입력하기 싫어서", "옮기다가 지쳐서" | **데이터 층** 장벽 | 옮기는 수고 자체가 문제인가 |
| "가족이랑 같이 써서", "손에 익어서", "어디 뭐 있는지 아니까" | **습관·관계 층** 장벽 | 기존 방식을 그대로 두는 게 전제인가 |
| "딱히 바꿀 이유가 없어서" | **동기 부족** — 가설 기각 | 불편이 기록 방식 바깥에 있는가 |
| "안 적어요, 그냥 기억해요" | 전환이 아니라 **처음 시작**의 문제 | 기록하지 않는 사람은 무엇에 기대는가 |

> **기록 안 함**이 절반을 넘으면 출발 가설은 이번 사용자군에게 맞지 않는 질문이다.
> 그 자체를 공감 단계 발견으로 `01-공감.md`에 적는다.
