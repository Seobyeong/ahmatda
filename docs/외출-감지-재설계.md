# 외출 감지 재설계 — [떠나기] 버튼 · 능동 알림 · 자기 전 설정 시간

> 기준일: 2026-11-03 / 상태: **결정 확정, 구현 진행 중**
> 관련 문서: [비서 기능 아이디어](비서-기능-아이디어.md), [경로 기억 설계](경로-기억-설계.md), [코드리뷰 펀치리스트](코드리뷰-펀치리스트.md)

## 0. 목표

1. 잠금화면에서 오늘 체크리스트가 보인다.
2. 나가기 전에 **[떠나기]** 를 누르면 남은 것을 짧게 한 번 보여준다.
3. [떠나기]를 안 눌렀든 눌렀든, **안 챙긴 게 남은 채로 나간 게 감지되면** 앱이 먼저 알린다.
4. 사용 초반에 **매일 자기 전, 사용자가 정한 시각**에 내일 챙길 것과 알림 성향을 맞춘다.
5. 알림을 자주 받길 원하는 사람에게는 **집 밖 장소에서 머물다 떠날 때**도 알린다.

## 1. 확정된 결정 (2026-11-03, 다시 논의하지 않음)

| # | 질문 | 결정 |
|---|---|---|
| 1 | [떠나기]를 누른 뒤 안 챙긴 게 남은 채로 나가면? | **그래도 알린다.** [떠나기]는 알림을 끄는 버튼이 아니라 "마지막 확인" 버튼이다. |
| 2 | 외출 확인 신호 | **걷기 감지 + 위치 감지가 주 신호**, Wi-Fi는 정확도를 높이는 **부가 검증**. |
| 3 | 자기 전 설정 시간 알림 | **22:00 전날 알림과 20:00 착장 피드백을 둘 다 대신한다.** |
| 4 | 집 밖 장소에서 머물다 떠날 때 알림 | **선택권을 주되 위치 '항상 허용'을 권장**한다. |

### 바뀌는 기존 결정
- 경로 기억 설계 5장 / 아이디어 문서 "하지 않을 것"의 **"외출 중 위치 계속 기록 안 함"** → 결정 4로 **옵트인(권장) 백그라운드 위치**로 완화한다. 계속 기록하는 게 아니라 "머묾 → 이탈" 판정에만 쓰고 좌표 이력은 저장하지 않는다 (8장).
- 9/16 "Wi-Fi BSSID 이탈 감지가 모든 면에서 빠르다, 위치는 집 밖 장소에만" → 결정 2로 **위치가 주 신호**가 된다. 다만 위치 이탈은 수십 초~수 분 늦으므로, **Wi-Fi 이탈은 "후보" 신호로 먼저 받아 두고** 걷기/위치 확인이 붙는 순간 바로 알린다 (3장). 결과적으로 알림이 Wi-Fi 단독보다 크게 늦지 않으면서 오탐이 줄어든다.
- 9/16 "20:00 고정 대신 귀가 시점 질문" 제안 → 결정 3으로 **사용자가 정한 자기 전 시각** 하나로 통일.

## 2. [떠나기] 버튼

**놓는 곳**
- 앱 대시보드 (1단계)
- 잠금화면 출발 상태 알림의 액션 버튼 — Android (1단계)
- Android 홈 위젯 — 앱을 `ahmatda://leave` 딥링크로 여는 방식 (2단계)
- iOS — 알림 액션은 펀치리스트 #8 결정 대기, 위젯/Live Activity는 macOS 확보 후

**누르면**
1. 오늘 [떠나기]를 눌렀다고 기록한다 (`leaveIntent: { date, at }`).
2. 남은 것이 있으면 **"마지막 확인" 알림**을 띄운다 — 헤드업, 10분 뒤 자동으로 사라짐, 액션 [다 챙겼어요].
   남은 것이 없으면 "다 챙겼어요, 다녀오세요" 토스트 + 출발 상태 알림 정리.
3. 외출 감지에 **"본인이 나간다고 말함"** 신호로 쓴다 — 확인 신호 하나만 붙으면 바로 외출로 판정 (3장).

**누른 뒤 나갈 때 (결정 1)**: 그 시점에도 안 챙긴 게 있으면 긴급 알림을 보낸다. [다 챙겼어요]를 눌렀으면 다 챙긴 상태라 자연히 안 울린다.

## 3. 외출 판정 — 신호 조합

| 신호 | 역할 | 지연 | 비용 |
|---|---|---|---|
| **걷기 시작** (Android Activity Recognition Transition / iOS CMMotionActivity) | 주 신호 | 수 초~1분 | 신체 활동 권한. 네이티브 모듈 필요 (Expo에 없음 — v57 문서 확인 필요) |
| **위치 이탈** (집 지오펜스 / 이동 거리) | 주 신호 | 수십 초~수 분 | 위치 권한. 백그라운드는 '항상 허용' |
| **집 Wi-Fi 이탈** (BSSID) | 부가 검증 · 빠른 후보 | 10초 디바운스 | 없음 (구현됨) |
| [떠나기] 누름 | 의도 신호 | 즉시 | 없음 |
| 학습한 평소 출발 시각 | 사전 확률 | — | 없음 |

**판정 규칙 (초안, 구현 시 테스트로 고정)**
- **외출 확정** = 주 신호 2개 (걷기 + 위치 이탈)
  **또는** 주 신호 1개 + 부가 신호 1개 (Wi-Fi 이탈 또는 [떠나기])
- **오탐 거르기**: Wi-Fi만 끊기고 걷기·위치가 없으면 외출 아님 (공유기 재부팅, Wi-Fi 직접 끔, 방 구석 약전계).
- 신호들은 **10분 창 안에서** 모였을 때만 묶는다. 오래된 신호는 버린다.
- 판정 로직은 `services/departure/decide.ts` 순수 함수로 분리하고 테스트를 같이 쓴다 (기존 `presence.ts` 원칙).

**권한별 저하 동작**
| 허용된 권한 | 동작 |
|---|---|
| 걷기 + 위치 '항상' | 위 규칙 그대로 |
| 걷기 + 위치 '사용 중' | 집에서는 걷기 + Wi-Fi로 판정. 집 밖 장소 알림은 없음 |
| 걷기 없음 | 위치 + Wi-Fi (지금보다 느리지만 정확) |
| 둘 다 없음 | 지금처럼 Wi-Fi 단독 |

## 4. 집 밖 장소에서 머물다 떠날 때 (결정 4)

- **설정:** 알림 성향이 "자주"이거나 사용자가 켰을 때만. 켤 때 위치 '항상 허용'을 권장하는 안내 화면을 거친다 (Google Play "눈에 띄는 공개" 요건을 겸함).
- **iOS:** 방문(Visits) 모니터링 — 머문 장소·떠난 시각을 저전력으로 받음.
- **Android:** 방문 API가 없음 → 걷기 감지가 멈춘 채 일정 시간(기본 20분) 지나면 그 자리에 지오펜스를 걸고, 이탈 + 걷기 시작이면 판정.
- **알림 내용:** 아침에 체크한 것 중 **꺼내 쓰는 물건**(충전기·우산·텀블러·노트북)만. 없으면 울리지 않는다.
- **알려진 한계:** Android는 앱이 종료되면 지오펜스가 와도 앱이 깨어나지 않는다 (9/16 v57 문서 확인). 걷기 감지 쪽은 매니페스트 리시버로 받을 수 있어 이 한계를 덜 수 있는지 구현 시 확인.

## 5. 자기 전 설정 시간 (결정 3)

- **설정:** `nightlyCheckTime` (기본 22:00, 온보딩 설문에서 받음). 기존 `day-before-alert`(22:00)와 `feedback-alert`(20:00)를 **하나의 `nightly-check` 알림으로 대체**한다.
- **내용:** ① 오늘 어땠는지 (추웠음/적당함/더웠음 — 기존 피드백 액션 유지) ② 내일 챙길 것 확인 ③ 알림 빈도 조정.
- **빈도:** 첫 14일은 매일. 이후에는 물어볼 게 있는 날만 (피드백이 학습을 바꿀 날, 내일 일정·날씨가 평소와 다른 날).
- **자정 넘김:** 00:30에 설정하면 "내일"은 달력상 오늘이다. 그래서 ① 알림 본문에 "내일"을 쓰지 않고 출발 시각만 말하고 ② 알림에서 받은 착장 피드백은 달력 날짜가 아니라 **지금 이전의 가장 최근 출발 시각이 속한 날**에 기록한다 (`getFeedbackOutingDate`).

## 6. 첫 사용 설문

9/16 결정(질문 최소, 나이·성별·직업 묻지 않음)을 지킨다. 답이 곧바로 설정을 바꾸는 질문만.
1. 알림 성향 — 필요할 때만 / 보통 / 자주 (→ 4장 켜짐 여부, 5장 빈도)
2. 자기 전 정리 시각 (→ `nightlyCheckTime`)
3. 주 이동수단 — 대중교통 / 도보·자전거 / 자차 (→ 우산·외투 기준선)

## 7. 잠금화면 표시

- **Android:** 폰 잠금화면 위젯은 OS 차원에서 없음 (Android 5.0에서 제거, 지금은 태블릿 일부만). → 기존 **출발 상태 알림(ongoing)** 에 [떠나기] 액션을 붙여 잠금화면 위젯 역할을 하게 한다. Android 16 Live Updates는 사용 조건과 notifee 지원 여부 **미확인**.
- **iOS:** 잠금화면 위젯(`accessoryRectangular`) 또는 Live Activity. macOS·Apple 계정 확보 후.

## 9. 구현 순서

1. ✅ **[떠나기] 버튼** — 대시보드 + 잠금화면 알림 액션, 마지막 확인 알림 (`2fcd0c8`)
2. ✅ **자기 전 설정 시간** — `nightly-check`로 두 알림 대체, 자정 넘김 처리. ① ✅ **보낼 날 고르기 + 외출 안 한 날 거르기** (아래) ② ✅ **다음 외출 준비 미리보기** — 정리 알림 탭/대시보드 버튼으로 열림. 그날 요일·일정·예보로 뜰 항목과 이유, "이 날만 추가"(항목 속성 문서의 특정 날짜 1회 `onDate`). 아침 체크리스트 우산 기준도 미리보기와 같게 맞춤(남은 시간대 강수확률 60%)
   - **2번 ① 상세 (2026-11-04 결정·구현)** — 규칙 `services/nightly/nightlyRules.ts`(테스트), 계획 `NightlyService.ts`, 외출 흔적 `outingLog.ts`.
     · 반복 알림 하나 → **날짜별 한 번짜리 6일 치 + 7일째부터 매일 반복**(`nightly-check-YYYY-MM-DD`, `nightly-check-tail`). 기본은 "평소처럼(피드백 포함)", 오늘 밤 것만 알림 3시간 전부터 판단해 바꾼다 — 앱이 몇 주 꺼져 있어도 기본 알림은 끊기지 않는다.
     · 외출 흔적은 달력 날짜가 아니라 그 시각이 속한 외출 날(`getFeedbackOutingDate`)에 단다 — 정리 시각이 자정 이후여도 리뷰하는 날과 맞게.
     · 외출 안 한 날: 착장 피드백 빼고, 다음 외출이 평소와 다를 때만 "다음 외출에 챙길 게 있어요"(없으면 건너뜀). 외출 여부를 모르면(관찰 빈틈·집 Wi-Fi 미등록·앱 종료) **외출한 것으로** 본다.
     · "집에 있었음" = 그날 외출 흔적 없음 + 출발 감시 창 시작부터 지금까지 집 Wi-Fi 관찰 사이가 2시간을 넘지 않음. 외출 흔적 = 외출 확정 / 집 반경 이탈(시간 무관) / 집 밖 장소 머묾 / 백그라운드 확인·앱 복귀 때 집 Wi-Fi 밖.
     · 처음 14일(온보딩 날짜 `onboardedDate`, 이 기능 전 기기는 처음 본 날부터) 뒤 "필요할 때만·보통": 다음 외출이 다르거나(비·폭염 예보, 일정 준비물, 그날만 항목) 최근 피드백 3번에 추웠음/더웠음이 있을 때만. "자주"는 매일. 예보를 못 받으면 "다름"으로 본다.
     · 알림 본문에 다음 외출에 달라지는 것 두 개까지 붙인다 ("다음 외출: 우산(비 예보 70%), …").
     · 실기기에서 확인할 것: ① 날짜별 예약 6개 + 반복 1개가 실제로 걸리는지(getTriggerNotificationIds) ② 집에 하루 종일 있는 날 백그라운드 확인 간격이 2시간 안에 드는지(제조사 배터리 최적화) ③ 업데이트 설치 직후 옛 반복 알림이 지워지는지
3. ✅ **첫 사용 설문** — 3문항 (온보딩 2단계 + 설정 화면). 2026-11-04 결정한 효과:
   - 알림 성향 3단계: **필요할 때만** = 출발 전 알림 없음(이탈 알림·자기 전 정리는 유지) / **보통** = 지금 그대로 / **자주** = 집 밖 머묾 알림 켜짐(7단계에서 구현, 지금은 "준비 중" 표시). 자기 전 정리의 "2주 뒤엔 물을 게 있는 날만"(필요할 때만·보통)은 구현됨(2번 ①).
   - 이동수단: **자차** = 우산은 지금 비 올 때만(예보로는 안 넣음, 미리보기도 같음) / **도보·자전거** = 체감온도를 쾌적 구간(18~26°C) 밖에서 1°C 더 극단으로
4. ✅ **판정 로직 순수 함수** (`services/departure/decide.ts`) + 테스트 17개 — 신호 없이 규칙만. 3장 규칙에 더해 확정한 것: 같은 종류 신호는 한 번으로 셈 / 집 복귀 신호(Wi-Fi 재연결·집 반경 재진입) 이전의 이탈·걷기는 무효, [떠나기]는 유지 / [떠나기] 단독은 후보도 아님 / 걷기·위치 둘 다 못 쓰면 Wi-Fi 단독 확정(지금 동작). **안전장치(2026-11-04 결정):** 주 신호를 쓸 수 있는데 안 와도(앱 종료로 신호 유실 등) 집 Wi-Fi 이탈이 **5분** 동안 복귀 없이 이어지면 확정. 10분 창과 무관하게 2시간 안의 마지막 Wi-Fi 상태를 본다
5. ✅ **걷기 감지 네이티브 모듈** (Android) — `modules/ahmatda-motion`. Play 서비스 활동 전환 API(걷기·달리기·자전거 시작)를 매니페스트 리시버로 받아 시각만 SharedPreferences에 기록(3시간 보관, 2분 안 중복 제거), JS가 살아 있으면 이벤트로도 전달. 재부팅·앱 업데이트 뒤 부팅 리시버가 구독 재등록. 권한은 온보딩 "신체 활동" 행(Android 10+ 런타임). Gradle 컴파일·매니페스트 병합 확인, **실기기 미검증**. iOS(CMMotionActivity)는 macOS 확보 후. **아직 판정에 연결 안 됨** — 6단계에서 위치와 함께 `decide.ts`에 연결
   - 실기기에서 확인할 것: 구독 재등록 시 Play 서비스가 다시 보내는 ENTER의 시각이 원래 시각인지 지금 시각인지 (지금 시각이면 2분 중복 제거로 못 거르므로 대책 필요)
6. ✅ **위치 신호 + 판정 연결** — 집 반경 150m 지오펜스(`services/departure/homeGeofence.ts`, expo-location + expo-task-manager), 신호 기록(`signalLog.ts`, 시각만 3시간 보관, 같은 출처의 같은 상태는 처음 시각 유지), 판정→알림(`DepartureService.ts`). Wi-Fi 리스너·백그라운드 폴링·지오펜스 태스크·걷기 이벤트가 모두 같은 `evaluate()`를 부르고, 당일 중복 방지 키(`wifi_alert_date`)는 그대로 쓴다. **동작 변화:** 걷기나 위치를 쓸 수 있으면 Wi-Fi 끊김만으로는 바로 알리지 않고 다른 신호 또는 5분 안전장치를 기다린다. 둘 다 없으면 지금처럼 즉시.
   - 2026-11-04 결정: 집 좌표는 **온보딩·설정의 [지금 위치를 집으로 등록] 버튼**으로만 저장(자동 저장 안 함, 기기 안에만). 위치 '항상 허용'은 **온보딩 권한 단계(선택 행) + 설정**에서 요청, 요청 전 Play "눈에 띄는 공개" 안내를 띄운다(`BACKGROUND_LOCATION_DISCLOSURE`).
   - 권한별: '항상 허용' 없으면 지오펜스를 걸지 않고 availability.location=false → 걷기+Wi-Fi로 판정(3장 표대로).
   - 가짜 신호 대책: Expo Android는 지오펜스를 `INITIAL_TRIGGER_ENTER|EXIT`로 걸고 프로세스가 새로 뜰 때마다 다시 건다 → JS 등록 시각·프로세스 시작 시각 뒤 60초 안 이벤트는 버리고, 그 밖의 반복은 기록의 중복 제거가 흡수.
   - 네이티브: `ACCESS_BACKGROUND_LOCATION`(AndroidManifest), iOS `NSLocationAlwaysAndWhenInUseUsageDescription`, app.json `expo-location` 플러그인(백그라운드 위치 켬, 위치 포그라운드 서비스는 안 씀 — 지오펜싱엔 불필요).
   - 실기기에서 확인할 것: ① 재부팅 뒤 지오펜스가 다시 걸리는지(Expo 태스크 복원이 OS가 지운 지오펜스를 다시 거는지) ② 실내 GPS로 집 등록 시 오차 ③ 앱이 백그라운드일 때 지오펜스 이벤트 지연 ④ 앱 종료 상태에선 지오펜스로 안 깨어남(문서상) — 그때는 걷기 기록·폴링·안전장치가 메우는지
   - 알려진 한계: [떠나기] 뒤 집 안에서 걷기가 잡히면 주1+부가1로 확정돼 현관 전에 알림이 갈 수 있다(4단계 규칙 그대로).
7. ✅ **집 밖 장소 머묾 → 이탈** — 규칙 `services/departure/awayPlace.ts`(테스트), 실행 `AwayPlaceService.ts`. 걷기 모듈이 정지(STILL) 시작도 기록(마지막 움직임 뒤 첫 정지만 유지 — 앱을 열 때 재등록 ENTER로 20분이 다시 시작되지 않게). 15분 백그라운드 폴링·앱 복귀·걷기 이벤트마다 `tick()`: 정지 20분+ & 집이 아님(집 좌표 반경+50m, 없으면 집 Wi-Fi, 둘 다 없으면 안 함) → 그 자리에 반경 150m 지오펜스 → 자리 이탈 + 걷기 시작이 10분 안에 같이 있으면 아침에 체크한 **꺼내 쓰는 물건**만 알림("두고 가는 거 없나요?"). 이탈 뒤 10분 동안 걷기가 없으면(차·GPS 튐) 자리를 푼다.
   - 2026-11-04 결정: 대상 물건은 **정해진 단어 목록**(`CARRY_KEYWORDS` — 충전기·우산·텀블러·노트북·이어폰·카드·지갑·안경·열쇠 등, '키'는 낱말 전체만) / 켜는 방법은 **"자주" + 설정의 별도 스위치**(`awayPlaceAlert: boolean | null`, null = 성향을 따름, 성향을 다시 고르면 null) / **한 장소 1번, 하루 3번까지**.
   - 필요 권한: 알림 켬 + 위치 '항상 허용' + 신체 활동. 켤 때(스위치·"자주" 선택) '항상 허용'이 없으면 공개 안내를 거쳐 권한다. 안내 문구에 "머무는 곳 하나(떠나면 지움)" 추가.
   - 저장: 지금 머무는 자리 하나(중심 좌표·시각, `away_place_state`) — 떠나거나 기능을 끄면 지운다. 장소 이력은 남기지 않는다.
   - 오탐·누락 대책(코드 리뷰 반영): 탈것(IN_VEHICLE) 시작도 기록해 머묾 판정에서 움직임으로 셈(지하철 중간역이 "머문 곳"이 되지 않게) / 위치 정확도 100m보다 나쁘면 자리 안 잡음 / 집 Wi-Fi에 붙어 있으면 위치를 켜지 않고, 한 번 처리한 정지(집·풀린 자리)로는 다시 위치를 잡지 않음 / 이탈을 놓쳤을 때(앱 종료 등) 머문 뒤 움직임이 있으면 30분에 한 번 위치로 확인해 자리를 풀고, 12시간 넘은 자리는 버림 / 프로세스 재시작 때 오는 이탈은 진짜로 봄(이탈만 받는 지오펜스라서)
   - iOS(Visits)는 macOS 확보 후. Android 앱 종료 상태에선 폴링·지오펜스 모두 안 깨어난다.
   - 실기기에서 확인할 것: ① 지하철·버스에서 STILL이 20분 넘게 잡혀 "머묾"이 되는지(되면 내릴 때 알림이 갈 수 있음) ② 실내(카페·사무실)에서 Balanced 정확도 위치 오차와 150m 반경 ③ 폴링 간격(15분+α)만큼 자리 등록이 늦어지는 체감
8. ✅ **홈 위젯 [떠나기] + 개인정보 문서 3종 개정**
   - 위젯 오른쪽에 [떠나기]. 누르면 앱이 `ahmatda://leave?n=<위젯이 발급한 임의값>`으로 열리고 대시보드의 [떠나기]와 같은 흐름(`pressLeave` + 토스트, App.tsx에서 받음). n은 위젯이 그릴 때마다 새로 발급해 이 앱 SharedPreferences에만 두고, 네이티브 `consumeLeaveNonce`가 지금(또는 바로 전) 발급값일 때만 한 번 통과시킨다 — MainActivity가 exported라 다른 앱도 이 링크를 보낼 수 있지만 n을 몰라 통하지 않고, 최근 앱 목록에서 다시 열 때 OS가 되돌려주는 예전 인텐트도 이미 쓴 값이라 무시된다. 스킴 intent-filter는 두지 않는다.
   - 개인정보처리방침: 백그라운드 위치·집 좌표·머무는 장소 좌표·신체 활동 시각·외출 판정 기록 항목과 보관 기간 추가. Play 데이터 안전성·Apple App Privacy: 기기 안에서만 처리 → 두 스토어 정의상 "수집 아님"(2026-11-04 도움말 확인), 답변 유지 + 근거 기록.
   - **Play 백그라운드 위치 신고서는 기능 하나만** 적을 수 있다 → "떠날 때 안 챙긴 물건 알림" 하나로 신고 (legal/google-play-data-safety.ko.md 7장). 공개 안내 문구를 Play 권장 문장에 맞춰 고침("앱을 닫았거나 사용하지 않을 때도 위치 정보를 수집해 …를 제공").
   - 출시 전 남은 것: 스토어 설명·웹사이트에 같은 공개 문구 싣기, 시연 영상(30초) 촬영, 법률 검토 표시 항목
   - 실기기에서 확인할 것: 위젯 [떠나기]로 콜드 스타트·백그라운드에서 각각 한 번만 처리되는지, 최근 앱 목록 재진입 때 다시 안 눌리는지

각 단계는 실기기 미검증 상태로 커밋되며, 타이머·스케줄링이 들어가는 2·4~7단계는 커밋 전 코드 리뷰를 돌린다.
