# 앱 실제 화면 캡처

2026-11-09, Android 에뮬레이터(Medium Phone, API 36, 1080×2400)에서 실제 앱(개발 빌드)을
실행해 `adb screencap`으로 찍은 원본이다. 도식이 아니다.

## 촬영 조건 (사실관계 주의)

- **날씨는 빠져 있다.** 이 PC의 `.env`에 기상청·에어코리아 키가 비어 있어서, 대시보드에
  "날씨 정보를 가져오지 못했어요"가 보인다. 키를 넣고 다시 찍어야 체감온도·시간대 예보·우산/마스크
  자동 추가가 나온다.
- **시스템 문구는 영어다.** 에뮬레이터 언어가 영어라 상단 빠른설정(Internet, Bluetooth 등)과 위젯 선택 화면은
  영어로 나온다. 앱 화면은 모두 한국어다.
- **시각은 촬영용으로 바꿨다.** 알림을 바로 띄우려고 출발 시각을 02:30·03:05로, 자기 전 정리 시각을
  02:10·02:39로 바꿨다. 화면의 시각이 새벽인 이유다.
- "오늘만" 항목 "USB"는 adb로 한글을 입력할 수 없어서 영문으로 넣었다.

## 못 찍은 것

- 날씨 카드 (API 키 필요)
- "아직 안 챙긴 것" 긴급 알림 (외출 확정까지는 됐지만 알림 표시 단계에서 오류 → 코드 수정함, 다시 찍어야 함)
- 캘린더 일정 연동 뱃지 ("09:00 '팀 회의' 연동됨"). 에뮬레이터에 일정이 없다
- "이번 주 N번 놓침" 뱃지 (놓친 기록이 쌓여야 나온다)
- 음성 입력, 잠금화면 (에뮬레이터에 화면 잠금이 없다)
